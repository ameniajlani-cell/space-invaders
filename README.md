👾 Space Invaders

A classic Space Invaders-inspired arcade game developed with Python and Pygame. This project recreates the original gameplay experience where players control a spaceship, defeat waves of enemies, and try to achieve the highest score possible. Developed as an introduction to game development using the Pygame library.

📌 Overview

This project was created to explore the fundamentals of game development in Python. It demonstrates key concepts such as game loops, event handling, collision detection, animations, and score management.

The player controls a spaceship, avoids enemy attacks, and shoots invading enemies to survive and earn points.

✨ Features
Player-controlled spaceship
Enemy invasion system
Shooting mechanics
Collision detection
Score tracking
Sound effects and game feedback
Keyboard controls
Classic arcade-style gameplay
